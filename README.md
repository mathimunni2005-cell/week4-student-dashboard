# Week 4 – Student Management Dashboard

A responsive front-end capstone project built with HTML, CSS, and JavaScript. It follows the Week 4 assignment's Student Management Dashboard option.

## Features
- Add, edit, and delete student records (CRUD).
- Save records in browser `localStorage`.
- Search by student name, email, course, or student ID.
- Filter by active/inactive status and course.
- Summary cards for total students, active students, and unique courses.
- Responsive table and mobile-friendly layout.
- Form validation and duplicate-email prevention.
- Demo data and a reset option.

## Project files
- `index.html` – page structure and add/edit form.
- `style.css` – dashboard styling and responsive layout.
- `script.js` – CRUD logic, search, filters, and localStorage.
- `README.md` – project information and publishing instructions.

## Run locally
1. Download and extract the project ZIP.
2. Open `index.html` in a modern browser.
3. Add or edit a student to test the dashboard.

No installation or API key is required. Data is saved in the browser used to open the page. For best results, keep the project open through a local development server or GitHub Pages.

## Upload to GitHub
1. Sign in to GitHub.
2. Create a **Public** repository named `week4-student-dashboard`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
4. Click **Commit changes**.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. Click **Save** and wait for GitHub Pages to publish.

Expected repository URL:
`https://github.com/mathimunni2005-cell/week4-student-dashboard`

Expected website URL after publishing:
`https://mathimunni2005-cell.github.io/week4-student-dashboard/`

These are expected URLs only. They will work after you create the repository, upload the files, and enable GitHub Pages.
